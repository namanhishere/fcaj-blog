# Worklog

I interned at Amazon Web Services Viet Nam Company Limited from 15/06/2026 - 12/08/2026 in the position Workforce Bootcamp - First Cloud AI Journey, and spent the whole period on one project: awsplace, a real-time collaborative pixel canvas whose production datastore is a C++23 Raft sidecar on ECS Fargate. Those 58 calendar days fall into nine working weeks, and the ninth is short because the internship ends on Wednesday 12/08/2026. The program guide describes a Week 1 to Week 12 worklog; a nine-week internship produces nine weekly entries, so that is what this section contains.

| Week | Dates | Focus |
|---|---|---|
| 1 | 06/15/2026 - 06/19/2026 | Onboarding and canvas data model |
| 2 | 06/22/2026 - 06/26/2026 | Go WebSocket server |
| 3 | 06/29/2026 - 07/03/2026 | Discord auth on Lambda and API Gateway |
| 4 | 07/06/2026 - 07/10/2026 | CDK infrastructure |
| 5 | 07/13/2026 - 07/17/2026 | RaftDB core |
| 6 | 07/20/2026 - 07/24/2026 | RaftDB integration, EFS and snapshots |

| 8 | 08/03/2026 - 08/07/2026 | Production cutover to `raftdb-only`, qualification and observability |
| 9 | 08/10/2026 - 08/12/2026 | Report, cost review and handover |
